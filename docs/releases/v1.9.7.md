# Bloomy v1.9.7

Swap now loads locally, then nudges through the network.

- Bloomy first loads and verifies the selected model on this Mac through the local API, keeping all advertised models available.
- After a successful local swap, Bloomy sends one network self-route nudge using the key already saved in Nudge. The request is capped at eight output tokens, with no paid fallback.
- Local loading and the network nudge have separate status messages. A missing or rejected key, unavailable model, or failed nudge does not undo a successful local swap.
- The nudge is skipped if the local request fails, is canceled, cannot be confirmed, or the provider becomes busy or changes. It does not enable automatic nudging.

Enable **Hosting → Fleet + local API → This Mac only** for local swapping. Set up the existing **Nudge** key once for the network follow-up. Network nudges may reach another owned provider and do not guarantee public work.

For Apple Silicon Macs running macOS 14 or newer.
