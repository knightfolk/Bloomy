# Bloomy v1.9.8

Fixes nudges getting stuck after a completed model selection change.

- Automatic and manual nudges now recognize a completed model switch as ready when the provider is otherwise fresh, idle, and serving exactly one warm model.
- The automatic watcher reports why it is paused instead of misleadingly saying it is watching when the provider is not eligible.
- The 15-minute idle threshold, saved key, cooldown, and daily limit remain unchanged. Active, failed, or unconfirmed switches still block nudges.

For Apple Silicon Macs running macOS 14 or newer.
