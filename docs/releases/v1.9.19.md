# Bloomy 1.9.19

Free space directly from Models. Downloaded model cards now include an
Uninstall button, with the observed downloaded size and cache location shown
before removal. A removed model returns to Available with a Download action.

Bloomy protects models that are enabled, loaded or still advertised by the
provider, and checks current state again before removing files. If the cache
location changes while confirmation is open, removal stops and requires a new
confirmation. Cached revisions are removed too; backups can delay when freed
space becomes available.

The removal command now uses the same provider configuration as the model
inventory, including custom cache locations. Ambiguous model identities and
unknown provider state keep Uninstall unavailable.

This patch preserves the provider's running work and saved selections. Bloomy
updates continue to use signed Sparkle packages; the provider CLI is separate.

Apple Silicon Macs running macOS 14 or newer.

This is a focused patch from the published 1.9.18 baseline. The unfinished
menu-bar Settings preview remains in development and is excluded from this
release; its animation diagnostic has not been declared fixed.
