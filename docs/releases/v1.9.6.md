# Bloomy v1.9.6

Switch what is loaded without narrowing the models you advertise.

- **Swap** is a separate action on advertised, unloaded popup model cards. It asks this Mac to load the selected model while keeping your advertised list and saved selection unchanged. **Only** remains available when you want just one model advertised.
- Swap sends one tiny request directly to the running provider’s unified local API. No cloud API key, network route, or paid fallback is used. Bloomy checks fresh local residency before reporting success.
- Swap requires an idle provider with one saved model slot and one loaded model. It rechecks activity and provider identity before sending. Incoming work can subsequently load another advertised model.
- If the local API is unavailable, **Open Hosting** takes you to its setup. Use unified mode bound to this Mac (127.0.0.1) and apply when ready. A standalone local server cannot change the network provider’s loaded model.

Swap uses the provider’s ordinary on-demand loading path; it does not pin residency, restart the provider, or change saved model selections.

For Apple Silicon Macs running macOS 14 or newer.
