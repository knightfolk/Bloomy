# Darkbloom Control v1.8.0

- Apply a saved model selection through Darkbloom 0.9.11's graceful live
  switch when fresh provider state confirms that the operation is safe. The
  popup also explains the CLI coordinator's automatic model loading without
  implying that Control changes models on its own.
- Add official Darkbloom fan-helper controls with bounded settings, exact
  executable identity checks, and the normal macOS administrator prompt.
- Add System, Light, and Dark appearance modes. System remains the default and
  follows macOS appearance changes.
- Record operational alerts locally, surface native notifications, and preview
  a bounded support packet that excludes credentials, prompts, responses,
  account identifiers, and filesystem paths.
- Add an observe-only recommendation evidence journal with explainable factors,
  deterministic replay, and clear insufficient-evidence states. Recommendations
  never issue provider commands.
- Improve Darkbloom 0.9.11 lifecycle presentation, including scheduled idle,
  startup preload, model-switch progress, retained slots, and safe timeout or
  forced-stop outcomes.

Coming soon: the iOS companion, remote QR pairing/control, and its persistent
Mac helper. The current download does not install or enable a remote-control
service.
