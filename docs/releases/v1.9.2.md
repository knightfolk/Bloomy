# Darkbloom Control v1.9.2

- Make the menu-bar popup easier to scan with three model cards per row, short
  model names, compact speed and earnings readings, and full names on hover.
- Show advertised and locally available models separately. Available models
  can be added directly; a confirmed “Use only” action switches the running
  provider to one downloaded model after accepted work drains.
- Recommend one model resident at a time in Capacity, with a startup model
  preference. Other enabled models can still load when requested. Saved model
  choices remain visible in a muted state when live provider status is absent.
- Clarify whether a model is serving now, in memory, or waiting to load, and
  simplify the popup's fan status and controls.

The provider CLI chooses among enabled models for incoming work. This release
does not add an earnings-based switching scheduler. A saved capacity change
requires a provider restart; switching the advertised model does not.
