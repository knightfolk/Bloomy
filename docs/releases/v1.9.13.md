# Bloomy v1.9.13

Activity now has separate Earnings and Metrics tabs. Local performance history
records measured serving speed, observed active time, provider request and token
counter increases, GPU use, model transitions, and native Autopilot phases.
Missing readings, provider restarts and counter resets remain explicit gaps.

Recording continues while Bloomy runs, even with the dashboard closed. Private
storage retains up to 30 days / 100,000 structured observations, retries failed
writes, and shows recording errors. Prompts, responses, API keys and raw logs are
excluded. No telemetry is uploaded.

Activity model filters now have consistent dimensions and spacing. Chart controls
align cleanly, and the new Metrics view supports narrow and wide windows, model
filters, local refresh, and 24-hour, 7-day and 30-day periods.

Autopilot phase is read-only and recognizes Darkbloom 0.9.16's shadow rollout.
This release does not enable Autopilot or change provider model settings.
