# Darkbloom Control v1.9.1

- Organize the sidebar into collapsible groups and split Settings into focused
  pages, preserving unfinished edits when switching between Settings pages.
- Simplify fan control around the official helper's on/off switch and live GPU
  temperature and fan readings. Keep optional policy adjustments out of the way.
- Hide unused legacy Gemma catalog entries while keeping configured or running
  models visible and manageable.
- Explain model-cache command timeouts without exposing private command output,
  and include the macOS external-volume usage description in packaged apps.

Fan changes still require the official helper's confirmation and administrator
approval. This release does not implement custom fan curves or a replacement
helper. iOS companion support remains in development for version 2.0.
