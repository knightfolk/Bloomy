# Bloomy v1.9.14

Activity → Metrics now tracks individual loaded-model visits, their observed duration, and switches that ended without observed work. Filter to **Without work** to inspect those visits and their combined observed time. Returning to a model creates a new visit. Missing readings, restarts, concurrent models and ambiguous counter changes remain uncertain. Completed request counters are recorded immediately so brief work between idle readings can still be detected.

The menu bar now has three compact circular indicators: the loaded model, whole-Mac GPU usage, and cooling. The model ring spins during fresh inference and uses the existing green/yellow/red temperature colors. The GPU ring shows utilization; the thermometer’s ring shows measured fan RPM as a percentage of the fan’s reported maximum. Hover for exact values, stale readings and alerts. Reduce Motion uses a static activity arc.

The fixed layout avoids shifting text, preserves the idle-alert !, and keeps missing sensor readings explicit. Menu Bar settings now explain the new indicators. Provider configuration and Autopilot enrollment are unchanged.
