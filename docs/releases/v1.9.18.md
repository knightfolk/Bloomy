# Bloomy v1.9.18

Action History keeps models visible in compact windows and gives full timestamps
more room. Searching for a few entries now puts their details close to the
results, with exact earnings amounts and complete model names still available.
Selection stays with its entry when resizing or refreshing; changing the filter
or search clears details that no longer belong to the results.

Repeated earnings recording does much less database work. Four controlled,
disk-backed recording workloads measured 35–48 times faster than v1.9.17, with
every retained field and event order matching. These measurements cover database
recording; they do not claim whole-app CPU, battery or provider speed gains.

For Apple Silicon Macs running macOS 14 or newer. Existing provider settings,
model selection and Autopilot enrollment are preserved. The broader native
polish, accessibility and performance review continues.
