# Bloomy v1.9.17

Health & Logs is easier to scan when a source fails or stops refreshing. Needs attention uses a concise status summary, while complete diagnostic messages remain selectable in Source freshness and available in expanded details and tooltips. Expanded daemon and thermal panels now align with their headings in wide windows. Long error paragraphs and model identifiers remain readable in compact layouts.

Deferred app updates now cancel replaced callbacks reliably. A waiting install handler cannot run after its updater owner has been released, and blocked polling no longer keeps that owner alive. Existing protection for unfinished edits and pending actions remains in place.

For Apple Silicon Macs running macOS 14 or newer. Provider settings, running models and Autopilot enrollment are preserved. The broader native polish, accessibility and performance review continues.
