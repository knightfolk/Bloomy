# Bloomy v1.9.15

Bloomy does less background work while keeping monitoring and local history active. Token averages update when measurements change, model cards share demand calculations, and hidden popup and Metrics views stop their display work. Fan panels share one polling loop, with fewer background checks for unchanged provider settings.

Electricity readings now save individually to an incremental local journal. Existing JSON history is imported safely and retained as a backup. Storage failures, missing readings, and measurement gaps remain explicit. Performance history also uses faster chronological queries and retention checks.

Settings and keyboard shortcuts now open the same dashboard window, preserving its selected page and staged provider changes. Contextual update and electricity links open their matching settings page. Native Edit and Window menus remain available.

Local performance metrics recognize Darkbloom 0.9.17's model-inventory refresh state. Provider configuration, Autopilot enrollment, and running models are preserved during the app update.
