# Bloomy v1.9.16

Bloomy brings a more consistent native Mac interface to the popup, dashboard and settings. Model cards keep their layout stable, startup choices explain what will actually preload, and errors leave Refresh and recovery controls available. Hosting connection details are now visible in the popup. Settings retain unfinished edits through refreshes, navigation and app-update requests.

Experimental Darkbloom Autopilot can be joined, paused, resumed or left from Provider settings using supported CLI controls. Bloomy distinguishes enrollment, shadow proposals and active control, and preserves your saved startup and memory choices. Enrollment does not mean live control is active.

Optional host GPU protection can warn or gracefully pause the provider after sustained high whole-Mac GPU use while it is idle. Configurable thresholds, recovery delays and minimum pause time prevent rapid cycling. A separate warning uses a recorded same-model speed baseline to flag possible contention during serving; it never interrupts accepted inference. These protections default to Off. Whole-Mac GPU readings do not identify individual apps.

Activity keeps the last completed report visible during refreshes and failures. Earnings charts preserve negative corrections, separate positive and negative stacks, and show tiny amounts precisely. Recorded zero, missing history and uncertain time boundaries have distinct presentations. Metrics qualifies historical visits and shows observed GPU use while idle without inventing missing measurements.

Background work is reduced through bounded history caches, faster log and visit analysis, incremental electricity storage and suspended display reads in hidden windows. Monitoring, local recording and enabled automatic actions continue while Bloomy runs. Native controls, compact layouts, focus handling and Quit cleanup have also been improved.

For Apple Silicon Macs running macOS 14 or newer. This update does not install the Darkbloom CLI, change Autopilot enrollment or move model files. The broader polish and accessibility review continues.
